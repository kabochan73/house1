# 部屋の模様替えアプリ 構想メモ

## 概要
Three.js（React Three Fiber）を使った、部屋に家具を配置してレイアウトを作る模様替えアプリ。ハッカソン向けのMVP。

## 機能リスト（MVP）
1. ログイン／新規登録（必須、name + password。ゲスト／未ログインでのローカル保存お試しモードは今回なし）
2. 部屋選択（3種類）
3. 家具配置（カテゴリーごとに3種類）
4. レイアウト管理（保存・一覧・編集・削除）

## 画面フロー
1. **トップページ（紹介ページ）**：軽いトーンでサービス紹介＋簡単な使い方説明（①部屋を選ぶ→②家具を配置する→③保存してダッシュボードに残せる、くらいの3ステップ）。ログイン／新規登録ボタンを配置。
2. **ログイン／新規登録画面**：name + password。
3. **ダッシュボード**（ログイン後のホーム）：保存済みレイアウトをカード形式で3列グリッド表示。各カードには3Dビューのサムネイル画像を表示（保存時に `gl.domElement.toDataURL('image/png')` でキャンバスをそのまま画像化し、レイアウトと一緒に保存）。右上に「NEW」ボタン（新規作成→部屋選択画面へ）。カードをクリックすると直接編集ページへ遷移。
4. **部屋選択画面**：部屋テンプレートを3種類用意。各テンプレートは家具が何も配置されていない空の状態（壁・床・照明のみ）。
5. **家具配置画面（編集ページ）**：選んだ部屋に家具を配置していく。家具はカテゴリー単位（ソファ・椅子・テーブルなど、5カテゴリー程度）で分かれており、各カテゴリーに3種類のデザインバリエーションがある。サイドバーの一番下に「Delete」ボタンを配置し、レイアウト削除ができる。
6. **保存**：部屋＋配置した家具（位置・回転）を1つのレイアウトとして保存し、ダッシュボードに戻る。

## 家具モデルとスケール
- モデルは自作せず、[Kenney.nl Furniture Kit](https://kenney.nl/assets/furniture-kit)（CC0ライセンス、GLTF形式）を利用。
- Kenney系アセットはゲーム制作向けのグリッド基準で作られており、実寸（cm単位）に忠実とは限らない。
- 部屋サイズは標準的な大きさに固定しつつ、各家具モデルには個別の `scale` 補正値を持たせて見た目のバランスを調整する方針。
  - 部屋 vs 家具全体のバランス → 部屋サイズ側で調整
  - 家具同士の相対サイズのズレ → モデルごとの `scale` 補正値で対応

## 技術スタック
- バックエンド：Laravel + Inertia（単一リポジトリ、`laravel/breeze --stack=react` で雛形生成）
- フロントエンド：React + Inertia のページコンポーネント
- 3D部分：React Three Fiber + `@react-three/drei` + Zustand（配置した家具の状態管理）
- 認証：Breeze標準の name / password ログイン（簡易認証でOK）
- DB：レイアウト（部屋テンプレート・家具配置）を保存

## データモデル（ざっくり）
- `users`: id, name, password
- `layouts`: id, user_id, room_template, name, thumbnail（画像パス or base64）, created_at
- `layout_items`: id, layout_id, furniture_type, position_x/y/z, rotation_y

## API / ルート（Inertia経由）
- 登録・ログイン（Breeze標準）
- `GET /layouts`：自分のレイアウト一覧（マイページ）
- `POST /layouts`：新規保存
- `GET/PUT/DELETE /layouts/{id}`：詳細・更新・削除

## シェア・コピー機能
- 各レイアウトに公開用の共有URL（ログイン不要）を発行できる。例: `/share/{layout_id}`
- 共有ページの内容：
  - 保存時にキャプチャしたサムネイル画像を大きく表示＋レイアウト名
  - 編集・削除などの操作は一切なし（静的な見るだけのページ）
  - 「このレイアウトを自分のダッシュボードに追加」ボタン
  - 下部に「このアプリで作ってみる→」のリンク（トップページへ）
- コピー動作：
  - ログイン済み：クリックで即コピー（同じ`layout_items`の内容を新しい`layouts`レコードとして自分のuser_idで複製）→ 自分のダッシュボードへ遷移
  - 未ログイン：ログイン／新規登録に遷移し、ログイン後に元の共有ページに戻ってコピーを実行

### 想定ユースケース
不動産屋の物件ページなどに部屋の共有URLを貼っておき、見た人がそこから家具配置をイメージ→気に入ったら自分のダッシュボードにコピーして自由にアレンジできる、という使い方を想定。

### 将来構想（今回のMVP範囲外）
今回は基本的に自分用のMVPだが、将来的には不動産サイト側にこの仕組みが一般化し、物件ごとに様々な人が作ったレイアウトを一般公開して誰でも探して自分用にコピーできる、というプラットフォームに広がることを見据えている。そのための種として、今回のMVPにも共有・コピー機能を入れている。

## MVPスコープ外（時間があれば後回し）
- 壁紙・床材の変更
- 家具のスケール変更（UI操作での拡縮）
- レイアウトのスクリーンショット保存・共有
