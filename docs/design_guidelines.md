# デザインガイドライン

白ベースで、海外SaaS（Linear / Vercel / Notion系）のようなスタイリッシュで余白のあるデザインを目指す。

## カラー
| 用途 | カラー | 備考 |
|---|---|---|
| 背景 | `#FFFFFF` / `#FAFAFA` | 白〜オフホワイト |
| テキスト（基本） | `#111827` 相当（濃いグレー） | 真っ黒は使わない |
| テキスト（サブ） | `#6B7280` 相当（ミドルグレー） | 補足情報など |
| アクセント | aqua系（`#06B6D4` 〜 `#22D3EE` あたり） | ボタン・リンク・選択状態など要所にのみ使用 |
| ボーダー | `#E5E7EB` 相当（薄いグレー） | カード・パネルの区切り |

アクセントカラーは使いすぎず、CTAボタンや選択中の状態（例：選んだ部屋テンプレート、選択中の家具）など「操作を促したい箇所」に絞って使う。

## タイポグラフィ
- サンセリフ（Inter系）
- 見出し：太め（semibold〜bold）
- 本文：通常（regular〜medium）

## コンポーネントのスタイル
- カード・パネル：薄いボーダー or ごく控えめなシャドウ、角丸（`rounded-xl`程度）
- ボタン：角丸、プライマリボタンはaquaアクセント背景＋白文字
- 余白：詰め込まず、セクション間・カード間にゆとりを持たせる

## 実装
- Tailwind CSS を利用（Laravel Breezeの標準構成と相性が良い）
- アクセントカラーは Tailwind の `theme.colors` にカスタムカラー（例：`accent`）として定義し、ハードコードせず一元管理する
